使い方

oshiire ／ Android 9 以降

「新しいメモ」を押して、書いて、浮かんでいるカメラのシャッターを押すだけ。写真はカーソルの位置に入り、すぐ続きを書けます。保存は自動です。

1. 画面の構成

画面の下にあるボトムナビゲーションで切り替えます。

場所画面
左「メモ」メモ一覧 → タップでメモの編集画面（さらに写真の書き込み画面）
右「設定」テーマ（システム／ライト／ダーク）、保存場所、バージョンなど

編集画面ではボトムナビゲーションを隠して、書く場所を広く取ります。左上の「←」か、端末の戻る操作で一覧に戻ります。

2. メモ一覧

  • メモは更新した日時の新しい順に並びます。
  • 左にサムネイル（メモの中の最初の写真）、右にタイトル・冒頭の文・日時が出ます。写真がないメモは、メモごとに色の違うアイコンになります。
  • タップするとメモを開いて編集できます。
  • 右下の「新しいメモ」で新しく書き始めます。
  • メモを左にスワイプすると削除します。すぐ下に出る「元に戻す」で取り消せます。

タイトルを付けなかったメモは、本文の 1 行目がタイトルとして表示されます。

3. メモを書く

  1. タイトルを入れる新しいメモでは、最初にタイトル欄にカーソルがあります。キーボードの「次へ」で本文に移ります。タイトルは空でもかまいません。
  2. 本文を書く普通のメモと同じように書けます。Markdown の記法（## 見出し、- リスト など）もそのまま書けます。
  3. シャッターを押す浮かんでいるカメラのシャッターを押すと、カーソルの位置に写真が入ります。文章の途中なら、そこで文章が前後に分かれます。
  4. 続きを書く写真のすぐ下にカーソルが移るので、そのまま続きを書けます。何枚続けて撮っても、撮った順に並びます。

写真のメニュー

メモの中の写真をタップすると、次のメニューが出ます。

メニューできること
写真に書き込む丸・矢印・文字などを書き込む画面を開く（6 章）
上へ移動／下へ移動写真を前後の文章・写真と入れ替える
写真を外すメモから写真を外す（写真のファイルは attachments フォルダに残ります）

上のバーのボタン

ボタンできること
カメラフローティングカメラを表示する／隠す
ギャラリー端末に保存済みの写真をカーソル位置に入れる
︙ → メモを削除このメモを削除する（保存フォルダの .trash に移ります）
保存ボタンはありません

入力が 0.5 秒止まるたびに自動で保存します。アプリを閉じたとき、画面を戻ったときもすぐ保存します。何も書かずに閉じたメモは残りません。

4. フローティングカメラ

編集画面の右下に浮かんでいる小さなカメラ窓です。メモを書きながら、いつでも撮れます。

操作動き
窓をドラッグ好きな場所へ移動
2 本指でピンチズーム
右下の角をドラッグ窓の大きさを変える
プレビューをタップそこにピントと明るさを合わせる
プレビューを長押しピントと明るさを固定（AE/AF ロック）。ダブルタップで解除
下の白い丸撮影
左上「－」最小化（丸いカメラボタンになります。タップで元に戻る、ドラッグで移動）
上中央の切替背面 ⇔ 前面カメラ
右上の拡大全画面カメラにする

窓の位置・大きさは、別のメモを開いても保たれます。キーボードを出すと、窓はキーボードの上に収まるように動きます。

5. 全画面カメラ

じっくり撮りたいときは全画面にします。撮った写真は窓のときと同じく、メモのカーソル位置に入ります。左下のサムネイルか左上の「×」、戻る操作でメモに戻ります。

機能説明
フラッシュ押すたびに オフ → オート → オン → ライト（点灯したまま）
タイマーオフ → 3 秒 → 10 秒
グリッド構図の目安になる 3×3 の線を表示
HDR明暗差の大きい場面をきれいに撮る（対応機種のみ）
露出補正スライダーで明るさを調整
ズーム倍率ボタン（0.5x・1x・2x など、機種による）またはピンチ
レンズ下のボタンで超広角・望遠などのレンズを直接選ぶ（「自動」はズームに合わせて切り替わるレンズ）
詳細設定マニュアルフォーカス、マニュアル露出（ISO・シャッタースピード）、ホワイトバランス、シーン（夜景・ポートレートなど）

出てくる項目は、その端末のカメラが対応しているものだけです。機種によって項目が違います。

6. 写真に書き込む

メモの中の写真をタップ →「写真に書き込む」で開きます。

道具使い方
丸囲みたい範囲を斜めにドラッグ
矢印根元から先端へドラッグ
四角斜めにドラッグ
ペン指でなぞって手書き
文字入れたい場所をタップして文字を入力
選択・移動描いたものをタップで選び、ドラッグで移動。ゴミ箱で削除、色を押すと色を変更
  • 色は 6 色（赤・黄・緑・青・白・黒）、太さは「細い／普通／太い」から選べます。文字の大きさも太さに合わせて変わります。
  • 上のバーで「元に戻す」「やり直す」ができます。
  • 右上の「✓」で保存します。保存せずに戻ると、変更を破棄するか確認します。
  • 書き込んだ後でも、もう一度開けば描いたものを動かしたり消したりできます（元の写真は残してあります）。

7. 保存のしくみと Obsidian

メモはデータベースではなく、ただのファイルとして保存します。フォルダの場所は「設定」→「保存場所」に出ています。

Android/data/space.webkombinat.oshiire/files/vault/
  2026-10-17_124831.md          ← メモ 1 つが 1 ファイル
  attachments/
    IMG_20261017_124905.jpg     ← 写真（書き込みがあれば書き込み入り）
    IMG_20261017_124905.orig.jpg       ← 書き込み前の元の写真
    IMG_20261017_124905.jpg.annot.json ← 書き込みの内容（描き直し用）
  .trash/                       ← 削除したメモ

メモの中身は次のような Markdown です。

# 朝のカフェ

今日は駅前のカフェへ。

![](attachments/IMG_20261017_124905.jpg)

ラテアートがきれい。

Obsidian で開くには

  1. vault フォルダを PC にコピーするスマホを USB で PC につなぎ、「ファイル転送」を選んで、上のフォルダを PC にコピーします。
  2. Obsidian で「フォルダを保管庫として開く」コピーした vault フォルダを選ぶと、写真付きでそのまま表示されます。

PC で書き足した .md をフォルダに戻すと、アプリの一覧にも出ます（![[ファイル名.jpg]] 形式の画像も読み込めます）。

アプリを削除するとメモも消えます

保存フォルダはアプリ専用の場所なので、アプリをアンインストールすると中身も消えます。大事なメモは PC にコピーしておいてください。

9. 困ったときは

カメラが映らない・「カメラへのアクセスが必要です」と出る

窓の「許可する」を押してください。一度拒否した場合は、端末の「設定」→「アプリ」→「oshiire」→「権限」→「カメラ」から許可できます。

「カメラが切断されました」と出る

ほかのアプリがカメラを使っている可能性があります。カメラを使うほかのアプリを閉じてから、窓を最小化して戻すか、メモを開き直してください。

カメラ窓が邪魔で文字が見えない

窓をドラッグして移動するか、「－」で最小化してください。上のバーのカメラボタンで完全に隠すこともできます。メモの最後には余白があるので、下までスクロールすれば窓に隠れずに書けます。

写真が横向き・逆さまになる

撮影したときのスマホの向きで写真の向きを決めています。スマホを机に平らに置いたまま撮ると、向きがずれることがあります。少し立てて撮ってください。

削除したメモを戻したい

削除した直後なら、一覧の下に出る「元に戻す」で戻せます。それを過ぎても、保存フォルダの .trash に .md ファイルが残っています。vault フォルダに戻すと一覧に出ます。

機種変更するときは

vault フォルダを PC 経由で新しい端末の同じ場所にコピーしてください。

解決しないときは GitHub の Issues で教えてください。
