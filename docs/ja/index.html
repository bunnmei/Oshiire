English

書いて、撮って、また書く。
写真つきメモをいちばん速く。

メモの上にカメラが浮かんでいて、シャッターを押すと写真がカーソルの位置にすぐ入ります。
ブログ記事のような写真入りのメモが、手を止めずに作れます。

使い方を見る GitHub

特徴

いつでも撮れるフローティングカメラ

編集画面に小さなカメラ窓が浮かんでいます。動かす・大きさを変える・最小化する・全画面にする、が自由自在。

撮った写真はカーソル位置へ

文章の途中で撮れば、そこで文章が分かれて写真が入り、すぐ続きを書けます。

標準カメラ並みの機能

レンズ切替、ズーム、タップでピント、露出補正、フラッシュ、タイマー、グリッド、HDR、マニュアル設定まで。

写真に丸・矢印・文字

貼った写真に、丸・矢印・四角・手書き・文字を書き込めます。あとから描き直しもできます。

Markdown で保存、Obsidian で開ける

メモは .md ファイル、写真は attachments フォルダに保存。フォルダごと Obsidian の vault として開けます。

保存ボタンはありません

書いたそばから自動で保存。アカウント登録、広告、通信は一切ありません。

必要なもの

  • Android 9 以降のスマートフォン（カメラ付き）
